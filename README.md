# S.N.U.S.

Saņemšanas & Nodošanas Uzskaites Sistēma
Lai izmantotu datubāzi ir nepieciešams ielādēt xampp. Pēc tam atvērt xampp un uzspiest Start uz MySQL un Apache. Kad vārdi Apache un MySQL aizmugure iekrāsojas zaļā krāsa un poga ir nomainīta no "Start" uz "Stop" tad ir jāiet uz phpmyadmin izmantojot pogu Admin, MySQL sadaļā. Kad atrodaties uz phpymsql jums ir jāizveido jaunu datubāze ar nosaukumu atslegas_sis un tad tajā datubāzē ir jāuzspiež uz opcijas "Import", un tad jaimportē atslegas_sis.sql fails tur iekšā. Pēc visa šī būs iespējams izmantot mysql datubāzi
P.S. XAMPP Apache un MySQL opcijām ir jābut visu laiku ieslēktam, kamēr tiek izmantots kods, lai varētu izmantot datubāzi.

Lai piekļūtu klāt mājaslapai ar localhost vispirms ir jāiet uz "This PC"->"Local Disk (C:)"->"xampp"->"htdocs" un tajā jāieliek jāizdzēš, kas tur ir iekšā un jāieliek S.N.U.S. folderis iekšā. Tad lietotājs var iet uz http://localhost/ un tad spiest "S.N.U.S.~"->"HTML"->"FrontP.php"
